# Todo List App

A Rails 8 Todo List application with Devise authentication, per-user tasks, task filters, and local email preview for development.

## Features
- User registration, login, logout, password recovery, and email confirmation
- Each user sees and manages only their own todos
- Create, edit, delete, and mark todos complete
- Filter tasks by all, pending, or completed
- Letter Opener email preview in development
- Docker-based local setup

## Run with Docker

Requirements: Docker Desktop with the WSL 2 engine enabled.

From the project directory, run:

```bash
docker compose up --build
```

Then open http://localhost:3000. The container runs database migrations automatically before starting Rails.

## Email preview

In development, open http://localhost:3000/letter_opener to view emails generated by the app. When a new account is registered, open the confirmation email there and click its confirmation link.

## Database

Development uses SQLite at `storage/development.sqlite3`. The database file is not included in the submission; Rails creates it from the migrations when the app starts.
